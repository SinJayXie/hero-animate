hero-animate · v1.0.2

让图标自己
长成窗口

iOS 风格的共享元素形变转场：窗口从触发按钮的矩形展开，关闭时沿同一条路径收回原处。框架无关核心，附带 Vue 3 / React 开箱即用组件。

install pnpm add hero-animate animejs
  • ESM
  • TypeScript
  • Vue 3
  • React 18+
  • Spring 可调

在线示例

页面里的弹窗与浮层都由本库驱动，点击图标试试。

Vue · 遮罩弹窗

窗口从按钮位置长出；点击遮罩空白处收回。示例自定义了弹簧参数。

React · 锚定浮层

ghostOnly 菜单从按钮右侧弹出，选择任意项即可收回。

快速开始

animejs 为必装 peer 依赖；vue / react 仅在引入对应子入口时需要。

Vue 3
<script setup lang="ts">
import { ref } from "vue";
import { HeroTransition } from "hero-animate/vue";

const open = ref(false);
</script>

<template>
  <button @click="open = true">📁</button>

  <HeroTransition :open="open" class="modal-mask"
                  @exited="open = false">
    <div class="modal-panel">…</div>
  </HeroTransition>
</template>
React
import { useState } from "react";
import { HeroTransition } from "hero-animate/react";

export function Demo() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button onClick={() => setOpen(true)}>📁</button>

      <HeroTransition open={open} className="modal-mask">
        <div className="modal-panel">…</div>
      </HeroTransition>
    </>
  );
}
核心 API · 任意框架 / 原生
import { createHeroTransition } from "hero-animate";

const hero = createHeroTransition(
  (root) => root.querySelector(".modal-panel"),
  { masked: true }
);

hero.onEnter(maskEl, () => {});  // 打开，结束调用 done
hero.onLeave(maskEl, () => {});  // 关闭
hero.cancel();                   // 中断并清理

API

核心选项与组件 props 一一对应，组件只是替你管理挂载与卸载时序。

HeroOptions

选项类型默认值说明
maskedbooleantrue 根元素是遮罩（内部找面板）；false 时根元素本身就是面板
panelSelectorstring".modal-panel" 面板选择器，用于在根元素内定位面板
anchor() => HTMLElement | null— 无指针来源时的锚点（快捷键打开等场景）
ghostOnlybooleanfalse 只动画克隆体，不写真实浮层 transform
springHeroSpringParams见下文 打开曲线弹簧参数
springAccelHeroSpringParams见下文 关闭曲线弹簧参数

组件 Props

Prop类型默认值说明
openboolean—必填，驱动打开 / 关闭
maskedbooleantrue同上
panelSelectorstring".modal-panel"同上
anchor() => HTMLElement | null—同上
ghostOnlybooleanfalse同上
spring / springAccelHeroSpringParams见下文弹簧参数

Vue：事件 entered / exited，其余 attrs 透传根元素。React：回调 onEntered / onExited，额外支持 className / style / children。

HeroHandlers

成员类型说明
onEnter(el, done) => void打开转场，结束调用 done
onLeave(el, done) => void关闭转场，结束调用 done
cancel() => void中断时间线、移除克隆层、还原被隐藏的触发元素

弹簧参数

只传想覆盖的字段，其余自动回落到 SPRING_PARAMS。打开与关闭曲线可分别配置。

自定义
import { createHeroTransition } from "hero-animate";

createHeroTransition(getPanel, {
  spring: { stiffness: 300, damping: 32 },
  springAccel: { stiffness: 280, damping: 30 },
});
字段含义默认值
mass质量，越大越迟滞1
stiffness刚度，越大越快250
damping阻尼，越小回弹越明显35
velocity初速度20

默认值同时以 SPRING_PARAMS 导出，便于在业务侧复用：import { SPRING_PARAMS } from "hero-animate"。

使用须知

  • CSS 约定：库不注入样式。遮罩的 backdrop-filter 会被读取为动画终点模糊值，面板圆角取 border-radius 自然值。
  • 包含块：组件在原地渲染。若祖先带 transform / filter / backdrop-filter，position: fixed 会以该祖先为包含块，建议把弹窗挂到 body（Vue Teleport / React Portal）。
  • 触发源：创建转场时自动安装 pointerdown 追踪（800ms 内有效）；快捷键打开等场景用 anchor 指定起点与收回终点。
  • 无障碍：系统启用 prefers-reduced-motion: reduce 时跳过动画，同步交回控制权。
  • 无触发源：既无点击来源也无 anchor 时，面板以本体中心轻微缩放淡入 / 淡出。
